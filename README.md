# A/B 测试分析框架（实验设计与分析全流程）

一套可直接复用的 A/B 实验分析流程：**样本量计算 → SRM 校验 → 基线平衡 → 主指标检验 → CUPED 方差缩减 → 分群异质性 → 多重比较校正 → 负面对照**。

> **为什么用模拟数据**：真实实验数据受保密约束无法公开。模拟数据的价值在于**已知真实效应**（转化率 +10%、GMV +4%、时长 +3%），可以验证分析流程能否正确检出效应、以及假阳性率是否可控。
> 全流程由 `scripts/` 下的脚本自动完成，报告见 `reports/ab_test_report.md`。

## 为什么这个项目值得讲

1. **覆盖实验分析的完整链路**，而不是只跑一个 t 检验：每一步都对应真实团队会踩的坑
2. **有"已知真值"的验证**：主指标检出了真实效应（方向与量级一致），负面对照（真值 0）未出现假阳性
3. **包含两个高阶方法的实操**：CUPED（方差缩减）与 Benjamini-Hochberg（多重比较校正）

## 每个环节解决什么问题

| 环节 | 解决的问题 | 不做的后果 |
|---|---|---|
| 样本量/功效计算 | 实验要跑多久、能检出多小的提升 | 样本不足 → 真实效应也检不出（假阴性） |
| SRM 校验 | 分流是否正常 | 分流有 bug → 两组不可比，结论全废 |
| 基线平衡检验 | 两组在实验前是否可比 | 随机化失败 → 效应估计有偏 |
| 主指标 + 置信区间 | 效应有多大、有多确定 | 只报均值 → 无法判断是否只是噪音 |
| CUPED | 用实验前指标降低方差 | 白跑更多样本、实验周期拉长 |
| 分群异质性 + 多重比较校正 | 哪些人群受益更大 | 在噪音里找故事（假阳性） |
| 负面对照 | 流程是否会产生假阳性 | 不知道结论有多大可信度 |

## 关键结论（来自本次运行）

- **样本量**：基线转化率 5%，要检出 10% 的相对提升，每组需要约 **32,000** 人
- **CUPED 效果**：访问时长方差下降 **14.1%**（等效节省约 16% 样本）；而零膨胀指标"人均 GMV"只下降 **0.8%** —— 因为 94% 的用户 GMV 为 0，协变量与结果的相关性被稀释
- **假阳性控制**：负面对照（真实效应 0）未出现显著结论；分群结果经 BH 校正后多数不再显著

## 可复用的地方

把 `data/ab_data.csv` 换成真实实验数据（需要列：`group`、`converted`、`gmv`、`session_duration`、`pre_gmv_30d` 等），直接重跑 `03_analyze.py` 即可得到完整报告。
